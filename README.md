# Life Expectancy Data Analysis
## Project Overview
This project was completed for MIS311 – Introduction to Business Analytics.
The objective is to perform Exploratory Data Analysis (EDA) on the Life Expectancy dataset using Microsoft Excel.
## Dataset
Dataset: Life Expectancy Dataset
The dataset contains information about countries, regions, infant deaths, under-five deaths, adult mortality, and life expectancy.
## Tools Used
- Microsoft Excel
- PivotTable
- Descriptive Statistics
- Histogram
- Scatter Plot
  ## Key Findings
- Countries with higher adult mortality generally have lower life expectancy.
- Average life expectancy differs across regions.
